# PayQuick

PayQuick is a stablecoin payment application built on Arc that enables small merchants and businesses to accept fast USDC payments through wallet transfers and QR code payment requests.

## Problem

Small businesses often struggle to accept digital payments that are fast, inexpensive, and easy to use across borders.

## Solution

PayQuick uses Arc's stablecoin-native infrastructure to make requesting and receiving USDC payments simple.

## Features

- Connect Wallet
- Send USDC
- Request Payments
- QR Code Payments
- Payment History
- Built on Arc Testnet

## Why Arc?

- USDC as the native gas token
- Fast deterministic finality
- Full EVM compatibility
- Stable transaction fees
